# 📊 Educational Data Analysis

Projeto de Data Science aplicada voltado para análise educacional, interpretação estatística e identificação de padrões comportamentais utilizando Python.

---

# 📌 Visão Geral

Este projeto realiza uma Análise Exploratória de Dados (EDA) aplicada ao contexto educacional, investigando relações entre:

- desempenho acadêmico
- entendimento do conteúdo
- percepção de dificuldade
- qualidade didática
- comportamento de aprendizagem

A proposta integra análise quantitativa, estatística aplicada e visualização de dados para gerar insights orientados por evidências.

---

# 🎯 Objetivos do Projeto

- Analisar padrões relacionados ao desempenho acadêmico
- Investigar relações entre didática, entendimento e dificuldade percebida
- Aplicar técnicas de análise estatística em contexto educacional
- Desenvolver visualizações analíticas para interpretação de dados
- Explorar conceitos de Behavioral Analytics aplicados à educação

---

# 🧠 Contexto Analítico

Mais do que gerar gráficos, este projeto busca compreender como fatores comportamentais e educacionais podem impactar processos de aprendizagem e tomada de decisão baseada em dados.

O projeto faz parte da minha transição estratégica para Data Science aplicada, integrando:

- Ciência de Dados
- Behavioral Analytics
- Educação orientada por dados
- Pesquisa científica
- Estatística aplicada
- Inteligência Artificial
